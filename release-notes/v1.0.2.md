# Track II v1.0.2

This beta maintenance release improves native notifications, admin diagnostics,
and public-source validation without changing the workout data model.

## Fixed and improved

- Native notification permission flows now recover after returning from iOS
  Settings and show a foreground confirmation when permission is enabled.
- Native permission failures now provide actionable device-settings guidance.
- The Admin Panel now uses an admin-only native debug action for previewing the
  update popup without contacting the release page.
- Embedded member-management cards were removed from the Admin Panel while the
  protected member directory remains available through its existing admin-only
  entry point.
- Added a secret-free validation workflow covering tests, typecheck, lint,
  formatting, maintainability, and the Cloudflare Pages build.

## Native release assets

- `Track-II-android-test.apk` is a debug-signed Android test build.
- `Track-II-ios-unsigned.ipa` is unsigned and must be signed before normal iOS
  distribution.
- `altstore-source.json` supports SideStore and AltStore updates.
