# Track II v1.0.14 — Responsive workout and sync reliability

This release tightens the workout experience across phone, iPad, desktop, and
native shells while preserving existing workout, account, sync, and offline
data.

## Workout UI

- Reworked set rows into one consistent responsive grid with aligned SET, unit,
  REPS, RIR, and completion controls.
- Kept set numbers and field labels readable on narrow mobile layouts without
  nested cards or clipped weight/unit text.
- Restored safe set deletion with a compact delete control, swipe/trackpad
  reveal, confirmation before removal, and a viewport-safe confirmation popup.
- Kept completed-set state and the one-thumb completion/rest action connected to
  the existing workout payload without changing stored values.
- Reduced unnecessary rerenders by isolating task/set editor state and
  retaining virtualization for long workout splits.

## Notifications and sync

- Centered and clamped notification surfaces to the visible viewport on phone,
  iPad, and desktop, including safe-area and browser visual-viewport changes.
- Moved the “Needs attention” sync details popup to the document overlay layer
  so the sidebar can no longer clip it; it now chooses the available side of
  the status control and scrolls internally when needed.
- Kept sync and announcement messages available until an explicit dismissal;
  transient undo feedback remains intentionally time-limited.
- Preserved notification center backdrop, clear-all behavior, and persistent
  local notification state.

## Release quality

- Added and maintained regression coverage for split switching, inbox flows,
  Rank navigation, calendar reverse transitions, mobile/iPad layout bounds,
  long workout scrolling, and set deletion gestures.
- Kept the offline app shell, local queue, draft recovery, sync conflict
  handling, distributed database-backed limiter, and server authorization paths
  additive and data-safe.
- Native production packaging uses the protected GitHub workflow to produce a
  release-signed Android APK/AAB and signed iOS IPA; optional TestFlight upload
  remains controlled by the workflow input.

## Verification

- Full source suite passes with 102 tests.
- Typecheck, ESLint, anti-slop lint, formatting, maintainability budgets, rank
  SVG validation, Pages build, and public desktop/mobile/iPad smoke checks pass.
- No changelog page or in-app release history was added.
