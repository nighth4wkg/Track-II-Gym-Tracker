# Track II v1.0.5 — Dashboard and release hardening

Track II is a responsive workout tracker for planning splits, recording sets, and syncing workout history.

## Added

- Session-accurate dashboard summaries with local calendar-day buckets, rolling periods anchored to today, and all-time totals from the first logged session.
- Server-side dashboard summary and revision endpoints for volume, progression lifts, and weekly muscle-set guidance.
- Realtime announcement delivery with a quiet polling fallback for offline or unavailable Realtime connections.
- Public unauthenticated browser coverage on every push and a protected authenticated staging workflow.
- A reproducible Sharp-based native icon generator that keeps the direct Capacitor 8 CLI unchanged.
- Distributed database-backed limiter remains enabled for protected network functions.

## Fixed and improved

- Dashboard volume and activity no longer merge multiple sessions just because they share a date.
- Year-to-date charts fall back to weekly buckets when all data is inside one calendar month.
- Stable Rank and recovery calculations are independent from timeframe selection.
- Release validation now reads the version from `package.json` and requires matching release notes.
- Supabase Edge Functions use one shared import map for the Supabase client dependency.

## Build from source

Install Node.js 22.18 or newer, run `npm install`, and use `npm run validate:release` for the public-build checks. Use `npm run package:pages:release` to create the upload-ready Cloudflare Pages ZIP.
