# Track II v1.0 — Beta release notes

Track II is a free workout tracker for personal use and sharing with friends.

## Added

- Workout splits with searchable exercise adding, editable sets, completion tracking, and finish-session history.
- Calendar history, muscle-group rank summaries, stopwatch/rest timer modes, unit conversion, and personal training metrics.
- Offline-friendly local saves with incremental Supabase sync, realtime refresh, conflict-safe merging, visible sync status, and a distributed database-backed limiter for protected network functions.
- Native APK/IPA update checks against the configured release page.
- Browser and native notification permission flows, including iOS Settings guidance after permission is denied.
- Settings for appearance, profile measurements, workout preferences, data export, AI image import, announcements, and protected admin tools.
- Safe undo for accidental set deletion and responsive desktop/mobile navigation.

## Fixed and improved

- Reduced sync work during rapid edits while keeping the polling fallback for disconnected realtime sessions.
- Standardized workout set columns, unit labels, input alignment, mobile safe-area spacing, search positioning, and bottom-navigation/toast placement.
- Removed expensive blur/filter work from moving surfaces and simplified entrance animations for smoother low-power mobile rendering.
- Made native notification checks recover when the app returns from iOS Settings and made permission confirmation visible while the app is open.
- Kept the Admin Panel focused by removing embedded member-data controls and adding an admin-only native update-popup debug action.
- Preserved private configuration boundaries: credentials, local paths, internal rollback context, and deployment-only material are not part of the public source or release package.

## Downloads

- `Track-II-v1.0-ios.ipa` — unsigned iOS native package for sideloading/signing.
- `Track-II-v1.0-android.apk` — installable Android native package.

## Build from source

Install Node.js 22.13 or newer, run `npm install`, then use `npm run validate:release` for the full public-build checks. Use `npm run package:pages:release` to create the upload-ready Cloudflare Pages ZIP.
