# Track II v1.0.12 — Reliability, recovery, and notification polish

This release consolidates the dashboard, workout, Rank, sync, and release
work completed since the previous published build.

## Workout and dashboard

- Added encrypted per-account workout draft recovery. An interrupted workout
  can be continued or discarded safely, and drafts are flushed before split
  changes or the app is closed.
- Added session-based dashboard aggregation with explicit local calendar-day
  boundaries. Repeated finishes on the same day and split count as one logical
  session while raw workout records remain intact.
- Stabilized timeframe calculations around the user’s first log and today,
  including Last week, Last month, Year to date, and All time.
- Kept metric identity stable: volume load remains volume load, with a clear
  positive or negative comparison where enough data exists.
- Reworked activity charts into discrete time slots with safe empty and
  partial-data states, readable labels, equal chart padding, and tooltips that
  stay inside the chart.
- Added the dashboard summary RPC for owner-scoped session counts, volume by
  period, PR feed data, and weekly muscle totals, with user/revision caching.
- Corrected logical session handling so duplicate Finish actions on one day do
  not inflate workout counts, charts, recovery totals, or history.

## Rank and exercise history

- Separated stable Rank and recovery calculations from timeframe-specific
  dashboard calculations and consolidated activity aggregation into one pass.
- Rebuilt the Rank map as a self-contained, flat SVG anatomy asset with
  semantic, selectable muscle regions for front and back views.
- Added keyboard, focus, hover, active, and reduced-motion-safe interactions
  without changing the existing rank color semantics.
- Fixed muscle detection and recovery totals so trained leg and other muscle
  groups are classified consistently across Rank and Recovery Radar.
- Added exercise-history progression details, Estimated 1RM trend data,
  grouped local session dates, and aligned load/RIR rows.
- Documented how to regenerate the Rank SVG and apply the project-specific
  transformations in `CONTRIBUTING.md`.

## Sync, offline work, and account safety

- Added a single color-coded sync indicator with Synced, Syncing, Offline, and
  Needs attention states, last successful sync time, and retry behavior.
- Added an encrypted offline workout queue with automatic retry, revision-aware
  conflict protection, and a visible conflict-resolution flow.
- Added realtime announcement delivery with per-user receipts so a dismissed
  announcement does not return after refresh.
- Added JSON/CSV workout export, password/email recovery states, and explicit
  account deletion through a protected server operation.
- Kept service-role access server-only and retained owner-scoped Supabase RLS
  checks for private workout data.
- Retained the distributed database-backed limiter for protected network
  functions.

## Notifications and interface polish

- Rest timer completion now sends a client-only notification when the next set
  is ready; it does not broadcast to other users.
- Announcement notifications now deliver immediately through the direct
  response and realtime path without duplicate alerts or avoidable delay.
- Fixed the dark-mode draft recovery action contrast, settings blank states,
  dropdown overflow, mobile workout field labels, header alignment, and
  responsive chart/tooltips.
- Added restrained shared transitions for split changes, setup flow, timers,
  dropdowns, lap actions, and Rank muscle selection, with reduced-motion
  fallbacks.
- Consolidated navigation, tokens, primitives, lazy screen styles, and
  maintainability budgets while removing repeated state and API branching.

## Release and operations

- Added unauthenticated Playwright coverage to every push and a protected
  authenticated staging workflow for sync scenarios.
- Added production smoke monitoring, latency/error budgets, and scheduled
  database backup export with isolated restore and RLS verification.
- Added dynamic package-version, tag, and matching release-note validation;
  the native workflow builds the Android APK and unsigned iOS IPA from the
  same versioned source.
- Preserved the direct Capacitor 8 CLI path and replaced the old asset
  generator without downgrading native tooling.
- Added the MIT license, third-party notices, repository security guidance,
  release packaging, and a verified Cloudflare Pages rollback archive.

## Data safety

- No existing workout, account, or Supabase records were modified or deleted
  by this release. Account deletion remains an explicit user action.
- The release includes no embedded credentials or service-role keys.
