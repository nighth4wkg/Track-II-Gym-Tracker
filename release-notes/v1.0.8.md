# Track II v1.0.8 — History and recovery accuracy

Track II is a responsive workout tracker for planning splits, recording sets, and syncing workout history.

## Fixed and improved

- Exercise history now includes a compact Estimated 1RM trend, groups sets under one local session date, and keeps load plus RIR aligned on one row.
- History volume labels use the logged weight unit directly, without the ambiguous `volume` wording.
- Recovery Radar now classifies raw weekly exercise rows through the same canonical muscle detector used by Rank, honors explicit group overrides, and falls back safely for older summaries.
- Sync status dots now use the visible green saved-state token; clicking the dot still opens the detailed status and retry panel.
- No workout data was modified, deleted, or migrated in this release.
- The distributed database-backed limiter and native-safe release paths remain enabled for the public build.

## Build from source

Install Node.js 22.18 or newer, run `npm install`, and use `npm run validate:release` for the public-build checks. Use `npm run package:pages:release` to create the upload-ready Cloudflare Pages ZIP.
