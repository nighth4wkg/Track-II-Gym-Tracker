# Track II v1.0.7 — Empty-state and sync polish

Track II is a responsive workout tracker for planning splits, recording sets, and syncing workout history.

## Fixed and improved

- Compact sync status is now represented by a color-coded dot in the shell and account footer. Clicking it opens the full status, last successful sync time, and retry action.
- The account sync details panel opens upward from the sidebar footer so it stays inside the viewport.
- Empty workout splits now show a structured Popular starters panel with catalog-backed add actions, plus clear library and AI import actions.
- Empty-state starter cards use the existing exercise-add flow, so they do not create duplicate data paths or change existing logs.
- The empty-state layout remains responsive and reduces to one starter column on very narrow screens.
- The distributed database-backed limiter and native-safe release paths remain enabled for the public build.

## Build from source

Install Node.js 22.18 or newer, run `npm install`, and use `npm run validate:release` for the public-build checks. Use `npm run package:pages:release` to create the upload-ready Cloudflare Pages ZIP.
