# Track II v1.0.11 — Continuous transitions and interactive anatomy

## Fixed and improved

- Creating, switching, and duplicating splits now keeps the workout surface in one shared transition instead of fading the old page away and popping in a replacement.
- Removed the transient completed setup panel that appeared and disappeared after a workout change. Setup guidance remains visible only while it is useful.
- Rebuilt the Rank body map as a continuous dark silhouette with smooth, independently selectable chest, delts, arms, core, back, and leg regions for front and back views.
- Rank muscle regions support tap, hover, keyboard selection, focus feedback, and restrained transitions while retaining the existing rank colors.
- Added a reduced-motion-safe fallback for browsers without the native View Transitions API.
- The distributed database-backed limiter and existing production safeguards remain enabled.
- Documented the reproducible Rank SVG generation command and Track-specific transformations in `CONTRIBUTING.md`.
- Restored SET, WEIGHT, REPS, and RIR headings on tablet/iPad workout layouts so labels stay aligned with their fields.

## Safety

- No workout data, sync records, migrations, or account data were modified by this release.
- Capacitor 8 and the existing Cloudflare Pages release path remain unchanged.
