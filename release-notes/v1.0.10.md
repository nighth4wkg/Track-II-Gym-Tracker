# Track II v1.0.10 — Logical sessions and production safeguards

## Fixed

- Repeated Finish actions on the same local calendar day and split now count as one logical workout session in dashboard and exercise-history summaries.
- Different splits remain separate, and raw workout/session records are preserved.
- Restored the missing “Add an exercise” step in the empty-split setup flow.
- Rounded and aligned the exercise-history trigger and modal heading.
- Added a visible merged-changes flow for offline or multi-device sync conflicts.

## Operations

- Added a controlled read-only production monitoring probe with latency and error budgets.
- Added a scheduled PostgreSQL backup export with isolated restore and RLS verification.
- Kept the distributed database-backed limiter and native Capacitor 8 CLI path unchanged.
- No user data was deleted, rewritten, or migrated by this release.
