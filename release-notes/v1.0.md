# Track II 1.0

Track II is a responsive workout tracker for planning sessions, recording sets, reviewing history, and following strength progress across muscle groups.

## Highlights

- Workout splits, exercise search, set editing, and automatic saving.
- Private Supabase authentication, realtime synchronization, a distributed database-backed limiter, and history.
- Calendar, notes, exports, strength ranks, stopwatch, and rest timer.
- Responsive light and OLED-dark interfaces with metric and imperial units.
- Optional notifications, haptics, AI import, and private admin tools.

## Native downloads

- `Track-II-android-test.apk` is an installable debug-signed Android test build.
- `Track-II-ios-unsigned.ipa` is unsigned and must be signed with an Apple developer identity before device installation or distribution.

The repository also contains the Cloudflare Pages-ready web source and complete setup instructions.
