# Track II v1.0.3 — Release notes

Track II is a free workout tracker for personal use and sharing with friends.

## Fixed and improved

- Fixed the mobile onboarding layout so the three setup steps and the `Create a new split` button have consistent spacing without overlap.
- Fixed update and announcement popups so they stay centered and inside the visible screen on mobile and desktop layouts.
- Kept workout logging responsive across narrow screens, including aligned set fields and mobile-safe navigation spacing.
- Preserved local saves, sync behavior, workout history, and existing user data while applying the UI fixes.
- Kept public source and release artifacts free of credentials, local paths, private account data, and deployment-only files.

## Downloads

- `Track-II-ios-unsigned.ipa` — unsigned iOS package for sideloading or signing.
- `Track-II-android-test.apk` — debug-signed Android test package.
- `altstore-source.json` — SideStore/AltStore source metadata for update checks.

## Build from source

Install Node.js 22.13 or newer, run `npm install`, then run `npm run validate:release` for the public-build checks. Use `npm run package:pages:release` to create the upload-ready Cloudflare Pages ZIP.
