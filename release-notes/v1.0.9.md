# Track II v1.0.9 — Sync and header polish

Track II is a responsive workout tracker for planning splits, recording sets, and syncing workout history.

## Fixed and improved

- Removed the duplicate mobile-header sync control; one sync-status dot now lives beside ACCOUNT and opens the full status panel when clicked.
- Syncing, saved, offline, and attention states now use explicit, visible dot colors with a subtle state halo.
- Centered the mobile header controls on the same vertical rhythm as the brand and menu button.
- Tightened the exercise-history modal header so long exercise names, the kicker, and close button share one stable alignment.
- No workout data was modified, deleted, or migrated in this release.
- The distributed database-backed limiter and native-safe release paths remain enabled for the public build.

## Build from source

Install Node.js 22.18 or newer, run `npm install`, and use `npm run validate:release` for the public-build checks. Use `npm run package:pages:release` to create the upload-ready Cloudflare Pages ZIP.
