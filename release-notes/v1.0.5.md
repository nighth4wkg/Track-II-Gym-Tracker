# Track II v1.0.5 — Release notes

Track II is a free workout tracker for personal use and sharing with friends.

## Fixed and improved

- Refined the shared dark UI surfaces, spacing, focus states, and mobile page rhythm.
- Fixed Dashboard activity inspection so hover and hold-and-slide map to the correct day, including Tuesday’s final slot.
- Fixed Rank header alignment so the eyebrow, title, and subtitle share the same left edge as the other pages.
- Fixed native release versioning so the in-app version, Android package, iOS package, and GitHub release use the same `1.0.5` version.
- Hardened native update checks with a stable GitHub release fallback and published release metadata.

## Downloads

- `Track-II-ios-unsigned.ipa` — unsigned iOS package for sideloading or signing.
- `Track-II-android-test.apk` — debug-signed Android test package.
- `altstore-source.json` — SideStore/AltStore source metadata for update checks.

## Build from source

Install Node.js 22.18 or newer, run `npm install`, and use the Native Release workflow with tag `v1.0.5` to generate the IPA and APK.
