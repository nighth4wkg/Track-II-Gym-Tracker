# Track II 1.0.1

This maintenance release refreshes the native installation experience while
preserving the existing workout data model and web features.

## Fixes

- Replaced the default Capacitor placeholder icon with the Track II app icon in
  Android and iOS release builds.
- Added a direct iOS Settings path when device notifications were previously
  blocked, with clear instructions for enabling them.
- Prevented a current native IPA or APK from showing an update prompt caused
  only by a newer web deployment.
- Moved the web update notice to a document-level overlay so it stays visible
  inside mobile and sidebar layouts.
- Reduced mobile settings spacing so notification controls and the Admin page
  remain reachable on short screens.

## Native downloads

- `Track-II-android-test.apk` is an installable debug-signed Android test build.
- `Track-II-ios-unsigned.ipa` is unsigned and must be signed with an Apple
  developer identity before device installation or distribution.
- `altstore-source.json` lets SideStore and AltStore install the IPA and find
  future releases.
