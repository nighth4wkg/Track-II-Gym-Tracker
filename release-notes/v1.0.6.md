# Track II v1.0.6 — Reliability and recovery

Track II is a responsive workout tracker for planning splits, recording sets, and syncing workout history.

## Added

- Sync health indicator with Synced, Syncing, Offline, and Needs attention states, last successful sync time, and retry.
- Offline workout queue backed by the encrypted local snapshot, automatic retry, and revision-aware conflict merging.
- JSON and CSV workout export plus permanent account and cloud-data deletion from Settings.
- Exercise history detail with session counts, best load, best volume, set history, and progression timeline.
- Clear empty and partial-data states for new users and timeframe filters without misleading zero or percentage values.
- Auth recovery polish for email confirmation resend, password reset, expired sessions, and network/server errors.
- Production smoke workflow for the deployed site, Supabase connectivity, username auth, email auth, and update manifest.
- Distributed database-backed limiter remains enabled for protected network functions.

## Fixed and improved

- Cold-start offline sessions now open the encrypted local workout snapshot instead of waiting for a network request.
- Dashboard activity and volume continue to use session identity and local calendar placement without changing stored workout data.
- Account deletion removes private public-table data in one protected transaction before the Auth user is removed.
- Exercise history reads are paginated and stay owner-scoped through Supabase RLS.

## Build from source

Install Node.js 22.18 or newer, run `npm install`, and use `npm run validate:release` for the public-build checks. Use `npm run package:pages:release` to create the upload-ready Cloudflare Pages ZIP.
