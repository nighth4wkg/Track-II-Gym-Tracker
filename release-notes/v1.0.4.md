# Track II v1.0.4 — Release notes

Track II is a free workout tracker for personal use and sharing with friends.

## Added

- Added an Apple-like three-step onboarding guide: create a split, add an exercise, and log the first set.
- Added a direct `Import split with AI` action beside the exercise-library button on empty splits.
- Added clear, public Gemini API-key instructions with links to Google AI Studio and key-safety guidance.

## Fixed and improved

- Added smooth setup-step transitions and a brief completion animation after the first set is logged.
- Made update status states consistent so error messages do not appear alongside `Up to date` or `No updates yet.`
- Improved mobile settings-tab positioning and aligned the version badge with the close control.
- Kept API keys memory-only and excluded credentials, local paths, private account data, and deployment-only files from the release source.

## Downloads

- `Track-II-ios-unsigned.ipa` — unsigned iOS package for sideloading or signing.
- `Track-II-android-test.apk` — debug-signed Android test package.
- `altstore-source.json` — SideStore/AltStore source metadata for update checks.

## Build from source

Install Node.js 22.13 or newer, run `npm install`, then run `npm run validate:release` for the public-build checks. Use the Native Release workflow to generate the iOS and Android artifacts.
